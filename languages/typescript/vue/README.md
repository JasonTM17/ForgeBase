# TypeScript Vue Starter

Production-oriented **Vue 3 SPA base**: Vite, strict TypeScript, typed env
config, app-level error handling, example component + service, vitest +
Testing Library, and an nginx-served Docker image.

## Quick Start

```bash
cp -r languages/typescript/vue ~/projects/my-app && cd ~/projects/my-app
cp .env.example .env && npm install && npm run dev
```

## Scripts

`dev` · `build` · `preview` · `lint` · `format:check` · `test`

## Configuration

| Variable        | Default         |
| --------------- | --------------- |
| `VITE_APP_NAME` | `forgebase-vue` |
